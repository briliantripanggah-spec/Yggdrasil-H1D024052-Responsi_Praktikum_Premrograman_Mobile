Nama Aplikasi : Yggdrasil
Yggdrasil adalah aplikasi pencarian anime yang memungkinkan pengguna untuk:

1. Melihat daftar anime.
2. Mencari anime berdasarkan judul.
3. Memfilter anime berdasarkan genre.
4. Melihat informasi detail anime.
5. Menampilkan data anime secara dinamis dari REST API.

Data anime yang digunakan berasal dari Jikan API, yaitu REST API untuk data MyAnimeList.
